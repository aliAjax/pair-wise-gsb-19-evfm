# hxwl-05 入缸排队台

水族店新鱼入缸排队管理：先检疫、再转展示，全程核对空间与水质，杜绝"只看水温就并缸"。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **缸位记录**：缸号、检疫/展示类型、水量、温度、盐度、缸容（尾数上限）、药水残留标记，水质可随缸况直接改
- **鱼批登记**：品种、数量、适温区间、适盐区间、观察天数，登记后进入待入区
- **排位核对**：自动或指定检疫缸，检查空间、水温、盐度、药水残留、原缸鱼耐受；缺项留在待入区并写明原因
- **入缸占用**：占用尾数由在缸鱼批推导，入缸即增加、出缸即释放
- **观察期**：按营业日期推进（可"+1 天"模拟），异常可标记/解除，期满且无异常才允许转展示缸
- **转展示缸**：转缸前复核对展示缸水质与空间，原缸位自动释放
- **中途换缸**：整批处理，数量不变、观察期不清零，履历记一笔
- **完成记录**：留档展示缸号、入缸水质快照、完成日期与全程入缸路径
- 数据保存在 localStorage，可一键恢复示例数据
