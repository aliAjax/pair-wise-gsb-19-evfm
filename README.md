# hxwl-05 新鱼入缸排队台

新鱼不能只看当前水温就并缸。排队台在排位时同时核清缸位空间、检疫缸是否可用、
药水残留、水温和盐度是否落在该批适温/适盐区间、以及原缸鱼耐受；缺项留在待入区并逐项写明。

## 技术栈

## 业务规则

- **缸位记录**：缸号、类型（检疫缸/展示缸）、水量、缸容（尾）、当前水温、盐度、药水残留。
- **鱼批记录**：品种、数量、适温区间、适盐区间、观察天数；整批处理，不拆分。
- **排位检查**（任一项不满足就留待入区并写明原因）：
  1. 空间：在缸鱼只 + 本批数量不超过缸容；
  2. 新鱼只能进检疫缸（检疫缸空不空）；
  3. 缸内无药水残留；
  4. 当前水温、盐度落在本批适温/适盐区间；
  5. 当前水质仍满足缸内所有原住鱼批的适温/适盐（原缸鱼耐受）。
- **入缸后**：缸位占用增加；鱼批进入检疫观察，按天累计观察天数。
- **异常处理**：标记异常期间观察天数暂停；异常解除后观察天数重新计。
- **转展示缸**：观察期满且无异常才可转；转缸再次逐项核对空间与水质，
  通过后释放原检疫缸位，完成记录留检疫缸号、展示缸号和转缸时水质。
- **中途换缸**：整批在检疫缸之间转移，目标缸同样全项核对，原缸位立即释放；不能借换缸直接进展示缸。
- 调水或清洗去残留后，待入区原因与原缸鱼耐受预警实时重算。
